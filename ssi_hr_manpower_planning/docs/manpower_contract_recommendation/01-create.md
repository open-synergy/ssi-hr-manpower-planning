# Create Contract Recommendation

> **Module:** `ssi_hr_manpower_planning`\
> **Model:** `manpower_contract_recommendation`\
> **Menu:** Human Resource > Configuration > Manpower Planning > Contract
> Recommendations\
> **Actor:** user in group _Manpower Planning: Manpower Contract Recommendation_

## Pre-Condition

- **Access:** user in group _Manpower Planning: Manpower Contract Recommendation_.

## Flow

1. Open the **Human Resource > Configuration > Manpower Planning > Contract
   Recommendations** menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the fields:
   - **Name** _(required)_: Enter the name of the recommendation.
   - **Code** _(required)_: Enter a unique code.
   - **Active**: Automatically checked.
4. Open the **Contract** tab.
5. Set the contract options:
   - **Terminate Contract**: Check it when the recommendation means the contract should
     be ended.
6. Click **Save**.

## Post-Condition

- A new contract recommendation is created and can be selected on the contract review
  lines of a manpower planning.
