======================
HR - Manpower Planning
======================

Manpower Planning (MPP) document per department and period. A planning
lists the planned formation per job position, reviews the employee
contracts of the department, and is approved through multiple approval.
It shows the needed versus filled manpower per job position (tab and
analysis report), can be printed as HTML, PDF and Excel, and the head
count snapshot stores the opening, joined, terminated and closing head
count of each period.

Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-hr-manpower-planning
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *HR - Manpower Planning*
6.  Install the module
