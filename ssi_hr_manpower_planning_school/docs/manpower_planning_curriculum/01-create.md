# Create Curriculum

> **Module:** `ssi_hr_manpower_planning_school`\
> **Model:** `manpower_planning_curriculum`\
> **Menu:** Human Resource > Configuration > Manpower Planning > Curriculums\
> **Actor:** user in group _Manpower Planning: Manpower Planning Curriculum_

## Pre-Condition

- **Access:** user in group _Manpower Planning: Manpower Planning Curriculum_.

## Flow

1. Open the **Human Resource > Configuration > Manpower Planning > Curriculums** menu.
2. Click the **New** button. **(14.0: "Create")**
3. Fill in the fields:
   - **Name** _(required)_: Enter the name of the curriculum.
   - **Code** _(required)_: Enter a unique code.
   - **Active**: Automatically checked.
4. Open the **Curriculum** tab.
5. Fill in the curriculum details:
   - **Description**: Enter a free-form description of the curriculum.
6. Click **Save**.

## Post-Condition

- A new curriculum is created and can be selected in the **School** tab of a manpower
  planning.
