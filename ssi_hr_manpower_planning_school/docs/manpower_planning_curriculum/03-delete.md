# Delete Curriculum

> **Module:** `ssi_hr_manpower_planning_school`\
> **Model:** `manpower_planning_curriculum`\
> **Menu:** Human Resource > Configuration > Manpower Planning > Curriculums\
> **Actor:** user in group _Manpower Planning: Manpower Planning Curriculum_\
> **Requires:** `01-create`

## Pre-Condition

- **Record:** The curriculum is not used by any manpower planning.
- **Access:** user in group _Manpower Planning: Manpower Planning Curriculum_.

## Flow

1. Open the **Human Resource > Configuration > Manpower Planning > Curriculums** menu.
2. Select one or more curriculums to delete (check the checkbox).
3. Click **Action** > **Delete**.
4. Click **OK** to confirm.

## Post-Condition

- The selected curriculums are permanently removed from the system.
